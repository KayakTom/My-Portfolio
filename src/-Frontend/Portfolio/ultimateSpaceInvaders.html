Overview

Ultimate Space Invaders is my own personal reimagination of a space invaders style game taking inspiration from numerous retro games, including Space Invaders and Galaga.

This project was created as part of my OCR Computer Science A-Level studies where I received an overall grade A in Computer Science and a grade A* for the coursework itself

For my hard-work on this project, I also received the Computer Science Award from Wyke 6th Form College where my teacher (Rhys Drury) highlighted:

"Thomas showed consistent hard work, outstanding attendance and a real passion for Computer Science. Thomas spent hours working on his NEA project which ended up being graded as an A*, a fantastic piece of work."

Project Information

This project was built as part of my A-Level Computer Science Coursework at Wyke 6th Form College.

It consists of a reimagination of the retro game Space Invaders using updated movement and updated game modes.

The creation of this project followed the Waterfall Lifecycle and included written documentation, regarding how the project was built across the time period.

The Frontend include the game menus and features, whilst the NodeJS backend hosted the server side allowing the use of the SQLite3 database.
